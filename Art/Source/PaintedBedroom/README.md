# Painted Bedroom: drop-in Unity package (experiment)

A walkable, fully 3D version of Van Gogh's *The Bedroom*, made by Serena Deng
with Claude. From the painter's spot it lines up with the canvas. From anywhere
else it is a real room: every object is a separate 3D model you can walk
around, pick up, turn over and put back.

**Status: experiment, not wired into the project.** This folder lives outside
`Assets/` on purpose: Unity doesn't import it, and it doesn't touch the Bedroom
scene (Rowling's). It goes into `Assets/` only after the team decides how it
relates to the Bedroom scene. The `.meta` files Unity needs are then made by
opening it in Unity, never by hand.

## Try it (about 2 minutes)

Unity 6000.3.23f1, the InnerFrame project (URP, Input System, XRI 3.3.2).

1. Copy the `InnerFrameBedroomWeb` folder into your project's `Assets/` folder
   (drag it into the Project window). **Don't commit that copy**: undo it with
   `git clean`, or delete it in Unity, when you're done.
2. Menu: **Tools > InnerFrame > Painted Bedroom > Import and Build (no Blender)**.
   It creates `Assets/InnerFrameBedroomWeb/Generated/` (meshes, materials, a
   prefab) and the scene `Assets/InnerFrameBedroomWeb/Scenes/PaintedBedroom.unity`.
3. Press Play and click in the Game view.

| Key | Action |
| --- | --- |
| W A S D, mouse | Walk, look (Esc releases the mouse) |
| Hold left click on an object | Carry it; scroll nearer/farther, Z/X turn it |
| Right-click (or I) on an object | Inspect it: turn it any way with the mouse, right-click to put it back |
| Backspace | Put everything back where the painting has it |
| F | Fly through furniture (Q/E down/up) |
| P | The painter's exact view, framed like the canvas |
| R | Back to the start |

On a Quest, the scene uses the team's XR Origin (XR Rig) from the XRI Starter
Assets, the same as the Gallery. Grab with grip, near or with the ray;
teleport anywhere on the floor.

## What's inside

| Path | What it is |
| --- | --- |
| `Data/room.json`, `Data/room.bytes` | The room: 37 named objects, their meshes (positions, normals, UVs, triangles, already in Unity's coordinates) and materials |
| `Data/Textures/tex_*.png` | 56 painted textures, generated by code (brushstroke canvases) |
| `Editor/PaintedBedroomImporter.cs` | Reads `Data/` and builds meshes, URP materials and the prefab |
| `Editor/PaintedBedroomBuilder.cs` | Builds the scene: colliders, movable objects, lighting, desktop and XR rigs |
| `Runtime/*.cs` | Desktop walker, desktop grab/inspect, the movable marker, rig selector |

**Movable (34):**
- **Bed:** Bed, Pillow_Back, Pillow_Front, Blanket
- **Washstand:** Washstand, Carafe, Basin, Pitcher, Tumbler, SoapDish, Bottle_Tall, Bottle_Short, BrushBox, ClothesBrush
- **Chairs:** Chair_Front, Chair_Back
- **Wall pictures:** Mirror, Picture_Landscape, Picture_PortraitMan, Picture_PortraitWoman, Picture_DrawingLeft, Picture_DrawingRight
- **Cloth and pegs:** Towel, Smock, Clothes_Dark, Cloth_Pale, PegRail, Hat
- **Openings:** Window, Door_Left, Door_Right

**Fixed:** Room_Walls, Room_Floor, Room_Ceiling, Room_Skirting, Door_Frames
(including a landing behind each door), and Window_View (a 3D square of
trees and houses seen through the window).

## How it was made

The room was built as a procedural three.js scene and fitted to the painting
from the painter's viewpoint. Colours were measured, and objects were placed
and scaled by comparing outlines against the canvas. It was then exported to
this format. The scene's code is not in this PR.
- Every texture is drawn by code: brushstroke canvases, including the small
  pictures on the walls.
- No pixels from the painting or from any third-party asset are included.
- Outlines are inverted-hull "ink" shells, so they work in VR.

## Known gaps (next steps)

- **The painterly look in Unity:** colour grading and a URP ink effect. The
  web study's screen effects did not carry over.
- **Textures:** sharper textures for objects you look at up close. Most are
  512 px.
- **Natural interactions:**
  - casements and doors on hinges
  - a sliding drawer
  - gravity for small objects
  - pictures that snap onto nails and clothes onto pegs

  Today everything is grabbed and floated freely.
- **Quest testing:**
  - frame rate with shadows on
  - about 450 meshes (combine the fixed ones if needed)
  - texture memory
  - comfort and room scale
  - hands vs controllers
