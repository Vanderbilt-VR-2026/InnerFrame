InnerFrame: bedroom painting details

IMPORTANT: In your current Unity screenshot the Console has a duplicate
PaintedWashJugExperiment compile error. In the Project search box search
PaintedWashJugExperiment, delete the OLD V5 copy, and keep the V5_Fix copy.
Wait until Unity has zero red compile errors before using this package.

Import:
1. Unzip. In Finder navigate to Assets/SerenaStyleExperiment/Editor.
2. Drag ONLY BedroomCompositionPass.cs into Unity's existing
   Assets/SerenaStyleExperiment/Editor folder. If the folder does not exist,
   create Assets/SerenaStyleExperiment/Editor in Unity first.
3. Open Bedroom_StyleExperiment.unity.
4. Choose InnerFrame > Serena > Apply Bedroom Painting Details.
5. Save (Command-S), compare the window, bed, chairs and coat rail with the
   painting, and inspect them from within the room in Play mode.

This updates only scene instance renderer materials. It does not alter the
prefab assets or interaction components. It creates new painted materials
in Assets/SerenaStyleExperiment/CompositionPass.
