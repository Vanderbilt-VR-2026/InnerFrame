InnerFrame painted Bedroom V4 — walk-around study

V4 uses the V3 wall, floor, wood and landscape textures already imported into your Unity project, wherever the V3 package sits under Assets. It adds one new interpretive portrait texture, deepens the wall color, warms the wood/floor, and vertically flips the small framed images to address the upside-down landscape. It applies only to the duplicate Bedroom_StyleExperiment scene.

INSTALL
1. Unzip this ZIP. Import the entire unzipped folder into Unity's Assets if that's easiest. V4 searches for the image files by name, so they do not need to sit directly under Assets/SerenaStyleExperiment. Keep the V3 files in the project.
2. Wait for Unity's import and compile to finish.
3. From the Mac menu bar choose InnerFrame > Apply Serena Bedroom Style V4.
4. View the room from the entrance and from two positions inside. If the landscape or portrait is still upside down, take a close screenshot; UV orientation may differ by mesh and can be corrected per picture.
5. Check Quest performance before treating the extra outlines and texture detail as production assets.

This is a style prototype. The portrait is generated interpretive artwork, not an authenticated copy of Van Gogh's actual room pictures. The original Bedroom scene and prefab assets are untouched. The script has been statically checked against your uploaded project; it has not been run in Unity on your Mac.
