# InnerFrame

## Preview the bedroom visual style

The updated bedroom textures and materials are in the `Bedroom_StyleExperiment` scene.

1. Open the Unity project from the `serena/bedroom-style-prototype` branch. If cloning a fresh copy, run `git lfs pull` in the repository folder to download the large assets.
2. In Unity's Project panel, search `t:Scene`.
3. Double-click `Bedroom_StyleExperiment`.
4. Inspect the room in Scene view.
5. Click Play and select the Game tab to test the runtime view.

Opening the project may initially show an empty Untitled scene. Open `Bedroom_StyleExperiment` manually to see the updated style.
