# What's in Assets/

Every top-level folder under `Assets/`, and every package folder under
`Assets/Samples/`, is listed here with where it came from and its license.

- **Adding a folder?** Add a row before you commit it. For anything the team
  didn't make, write down the source, the version and the license.
- **Format:** write each folder path in backticks, exactly as it appears in
  the repo, e.g. `` `Assets/Samples/XR Hands` ``.
- **The check:** `scripts/check-assets.sh` (check C9) prints a warning for
  every folder that is missing from this file. A warning doesn't stop a push,
  but please fix it.

## Made by the team or generated by Unity

| Folder | What it is | Source | License |
|---|---|---|---|
| `Assets/Scenes` | The project's scenes | Made by the team (`SampleScene` came with Unity's Universal 3D template) | Team work |
| `Assets/Settings` | URP render pipeline assets, renderers and volume profiles | Created with the project from Unity's Universal 3D template | Unity template content, no separate license file |
| `Assets/TutorialInfo` | The template's Readme panel and its editor script | Unity's Universal 3D template | Unity template content, no separate license file |
| `Assets/XR` | XR Plug-in Management and OpenXR settings | Generated by Unity: XR Plug-in Management 4.7.0, OpenXR 1.16.1 | Generated settings |
| `Assets/XRI` | XR Interaction Toolkit project settings | Generated by XR Interaction Toolkit 3.3.2 | Generated settings |

## Package samples (third-party)

Imported with Package Manager (select the package, then the **Samples** tab).
They are unmodified, except that Unity upgraded their materials to URP on
import. Their models, textures and audio are stored in Git LFS. To update a
sample, re-import it from Package Manager instead of editing it here.

| Folder | Contents | Source | Version | License |
|---|---|---|---|---|
| `Assets/Samples` | The folder Package Manager creates for imported samples | Unity | n/a | See the rows below |

The package's *Third Party Notices.md* lists Apache-2.0 components (gesture code from Google's ARCore Unity SDK). |
