# What's in Assets/

Every top-level folder under `Assets/`, and every package folder under
`Assets/Samples/`, is listed here with where it came from and its license.

- **Adding a folder?** Add a row before you commit it. For anything the team
  didn't make, write down the source, the version and the license.
- **Format:** write each folder path in backticks, exactly as it appears in
  the repo, e.g. `` `Assets/Samples/XR Hands` ``.
- **The check:** `scripts/check-assets.sh` (check C9) prints a warning for
  every folder that is missing from this file. A warning doesn't stop a push,
  but please fix it.

### Notes on the bedroom style assets (Serena Deng)

The bedroom style assets were developed through a ChatGPT-assisted, reference-guided procedural modeling and texturing workflow. ChatGPT helped author scripts that build geometry and generate painted PNG textures. Serena ran and previewed the assets in Blender, then exported/imported the resulting assets into Unity and positioned them in the bedroom style scene.

The reviewed Blender scripts include `InnerFrame_Window_Blender.py`, `InnerFrame_Window_Blender_V2.py`, and `InnerFrame_Bed_Ceramics_Blender.py`. They build objects from primitives/custom meshes and generate paint textures using seeded randomness, color variation, and brush-stroke marks. These scripted textures should be described as procedurally generated, rather than assumed to be AI image-generation outputs.

This entry records the supported development workflow; it does not assign a blanket license to all project assets. Before finalizing attribution:
- Record the exact source and applicable license of the reference image used for artwork crops.
- Verify the final retained model/texture inventory against the generation scripts and any other inputs.
- Record any externally sourced or image-generated assets separately if found.
- Update `Assets/InnerFrame_Unity_Assets/README.txt`, whose model/texture counts no longer match the expanded folder.

### Notes on the Tripo models in the Painted Bedroom (Charlyne Dong, 10/29)

Four objects in `Assets/InnerFrameBedroomWeb` are AI-generated meshes made with [Tripo](https://www.tripo3d.ai) (web app, Pro plan, account of Charlyne Dong), replacing the earlier procedural ones: `Chair_Front` and `Chair_Back` (one shared chair model), `Bed` (frame, mattress, sheet and blanket in one model; it replaces the separate `Blanket` object), and `Pillow_Back` and `Pillow_Front` (one shared pillow model).

- **Inputs:** multi-view images made with OpenAI's GPT Image 2.5 from the team's concept sheet of the room, which was itself generated from *The Bedroom* (public domain). The pillow views used renders of the Tripo bed as the style reference.
- **Outputs kept:** Tripo's mesh (HD model, then Tripo's quad retopology) and its base-colour texture, written into the room data by `Art/Source/PaintedBedroom/blender/room_io.py` as `Data/Textures/Chair_tripo_basecolor.png`, `Bed_tripo_basecolor.png` and `Pillow_tripo_basecolor.png`.
- **License:** generated on Charlyne's paid Tripo plan (Pro), so under Tripo's Terms of User Agreement (last updated July 11, 2025), §5.2.2 Paid Users, she has the rights to the outputs (use, copy, modify, publish, distribute, …), with Tripo keeping a royalty-free licence to use and display them for running the service, as quoted in the `Assets/VanGogh/Art/Vincent` row (https://www.tripo3d.ai/terms).
- The source `.glb` files and the GPT view images are kept locally, not in the repo.

Added 10/29 (same terms, same pipeline): `Washstand` (a Tripo side table), `Basin`, `Pitcher`, `Carafe` (a turquoise vase), `SoapDish`, `ClothesBrush` and `Towel` (with its wall hook). Later on 10/29: `Tumbler`, `Bottle_Tall` and `Bottle_Short` (one Tripo bottle, the short one 0.90 of its height; paper label painted out of the texture), glass at 40–45 % opacity. Also `PegRail`: one Tripo model of the peg rail with the three garments that used to be `Smock`, `Clothes_Dark` and `Cloth_Pale` (those objects are gone), and `Hat` (a Tripo straw hat on its right-hand peg). The basin's inner floor was lowered and the pitcher hollowed in Blender by script (Tripo outputs closed solids); each was scaled to match the team's concept sheet.
