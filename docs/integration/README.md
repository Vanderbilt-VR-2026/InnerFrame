Voice-first music policy: all Entrance/Gallery/Bedroom/Starry Night music sources share the director's speech-priority gain. During Vincent's scripted/AI/remote speech or a local recording/request, music falls to 25% (about -12 dB) with an 80 ms attack, stays low for 350 ms after speech, then recovers over 1.2 s. Future scene BGM must use this same priority behavior and test speech, recording, short gaps, failures and scene changes before delivery.
