The Player Menu

A small panel you call up in the headset with the ≡ button. It does two jobs: take you back to the scene you came from, and, soon, let you talk to the painter.

It opens half a metre in front of you and stays where it is in the room. Grip the title bar to move it. It works in every scene with an XR rig, and nothing has to be added to a scene.

Back

Ready

Every scene is a room in the museum. The Back button is the way out, so a player is never stuck in a painting.

  • Came from a sceneGoes back to it. The label names it: Back to Gallery.
  • Started hereGoes to the Gallery, the home scene.
  • In the Gallery, nowhere to goThe button is hidden.

It uses the existing SceneFader: the view fades to black, you leave the Photon room cleanly, and the other scene fades in. The target scene must be in Build Settings.

Talk

Waiting on the proxy

The start of the AI conversation with Vincent. Press once to speak, press again to send. The answer appears in the panel word by word, as it is written.

POST {serverUrl}/npc/{SceneName}/listen form field audio = 16 kHz mono 16-bit WAV header X-Access-Code (optional) ← plain text, streamed as it's written

The AI key never goes in the app. A Quest build can be unpacked, and the repo is public, so the key lives only on the proxy server.
